## 现在如何使用

打开原位置的 `Application\AI-Game-Workstation.exe`。若此前窗口仍在运行，请先保存当前修改，再关闭、重新打开，以加载新版。

| 工作区 | 可操作内容 |
| --- | --- |
| 3D 创作 | 人物、物品、场景灰盒三个入口；制作画布；资产视口 |
| 动画 | 动作参考画布；手动骨骼正/侧/顶视图；媒体与模型视口 |
| 美术与材质 | 参考画布；图片和视频查看 |
| 虚幻 5 | 蓝图检查；代码测试；参考画布；图片和视频查看 |

在每个画布中，把项目资产抽屉里的文件拖入，或从资源管理器拖入文件。后者先复制到项目 Assets，不覆盖来源文件。同一次外部拖入可包含多文件；当前上限 30 个、单文件 256 MB。失败的文件逐项反馈。

从素材节点输出端拖线到参考节点的 models/images/videos 等输入。带 ∞ 的端口允许多个来源；同一输出也可以接到多个目标。同一对端口不能重复连接，单值端口仍限制一个来源。拖动期间会显示曲线和目标端口反馈。多参考没有强制执行顺序，也不需要先连接才能单独预览。

图片/模型/视频节点选中后点击“打开资产视图”。GLB 使用真实静态网格预览；图片显示尺寸；视频可以播放、定位时间、保存当前参考帧。图片和视频可以保存人工参考说明，视频说明另含起止时间。参考帧记录来源视频的 ID、版本和时间点。人工标注会进入“整理 AI 参考”的结构化上下文。

媒体预览当前有大小及格式边界：图片/GLB 上限 32 MB，视频上限 64 MB；视频是否可播放取决于内置 Chromium 支持的编码，WebM/VP8 已实测。其他格式可能需外部编辑或转换。GLB 的压缩、稀疏及部分扩展也可能需要先转换。

“整理 AI 参考”展示本机整理的图、全部资产版本/哈希、所有连线用途、媒体标注，以及动画工作区已保存的骨架草稿。不会自动发送媒体或调用付费模型；用户可先核对后复制。

## 手动骨骼

动画 → 手动骨骼 → 选择自己的 GLB → 载入模型轮廓。轮廓来自 GLB 实际顶点和层级变换。载入不会自动移动已有手动关节。需要初始参考时，显式点击“按模型边界放入关节草稿”。

拖动关节点，或选择关节后输入 XYZ；正视图操作 X/Y，侧视图 Z/Y，顶视图 X/Z。提供左右镜像、撤销/重做和保存。坐标按 glTF 的 Y 向上、米记录。检查父级循环、无效坐标、缺少父级和零骨长。

**当前保存的是人工关节定位草稿，尚未创建蒙皮权重，也未完成角色变形或动画播放。** 三视图适合精确定位；完整透视操纵器、权重涂抹、骨长约束和正式 Blender 骨架/蒙皮导出仍需后续开发。

## UE 蓝图和代码

蓝图检查：在 UE 中选择实际节点，Ctrl+C，在本软件“蓝图检查”粘贴并显示。解析真实节点名称、类、位置、GUID、引脚及 LinkedTo，绘制节点和连接。问题列表可定位相应节点。保存时保留原始文本，可整理为 AI 检查上下文。

检查范围为当前复制的子图：范围外节点作为警告；缺失引脚、重复名称/引脚、错误方向等按结构问题报告；基础类型不同提示需 UE 复核。此检查没有执行 UE 编译，不替代对象继承、动态类型或隐式转换验证。

代码测试：选择真实 `.uproject`，读取已有 `Source/*.Target.cs`，选择目标后点击 Development 编译。通过安装引擎的内置 dotnet 调用 UnrealBuildTool，使用参数数组，不拼接任意 shell 命令。显示引擎、工程、目标、状态、日志和退出码，支持停止。构建会写工程的 Intermediate/Binaries 等目录，界面已说明。未找到 C++ Target 时不提供可执行编译按钮。

**代码构建入口已实现，但本轮没有用户指定的 C++ 工程，因此没有完成真实 UE 项目编译验收；也未完成 UE 插件桥接、蓝图回写、蓝图编译或运行测试。** 对 UE 代码目标读取和跨项目隔离已有自动化测试。当前蓝图 UI 验收使用符合 UE 导出格式的合成文本，未把合成样例声称为从用户工程读取。

## 当前未完成的识别能力

图片尺寸、视频解码和参考帧提取已实现；**图像语义识别、模型重建、视频人物/动作/姿态识别尚未接入视觉或姿态模型**。人工标注是用户明确输入的参考，不冒充识别结果。后续需选择可用的本地模型或视觉服务，实施时间范围/人物选择、识别结果编辑和对应真实样本验收。

当前 3D 人物/物品/场景是制作类别和参考组织入口；没有宣称三个入口都能自动生成任意模型。原有木箱/石柱/灰盒固定工具仍可使用，输入的图片/视频不会未经适配就改变这些固定配方。

其他待补：真正的部件/面编辑与装配、正式绑定和蒙皮、视频动作资产闭环、UE 实时桥接、AI 建议差异审阅、内部资产抽屉多选拖动、媒体片段循环播放、关闭前未保存提示。当前退出应用前仍需手动保存画布、骨架和蓝图文本。
