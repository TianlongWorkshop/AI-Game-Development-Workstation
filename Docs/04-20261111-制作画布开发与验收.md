# 制作画布开发与验收记录

日期：2026-11-11；应用版本：2.0.0-preview.4。

依据：交付文档 v0.3《游戏制作画布详细设计》和《提示词手册》。本次交付是文档 A/B 阶段的首批可运行实现，**不代表六阶段全部完成**。

## 打开和使用

1. 启动 `[local drive]\AI-Game-Workstation-2.0-preview\Application\AI-Game-Workstation.exe`，创建或打开项目。
2. 顶部进入“工作流”。首次显示“模板建模 → 保存项目资产”画布。
3. 单击模板节点，在右侧选择木箱、石柱或场景灰盒。
4. 拖动标题移动节点；空白处拖动平移；滚轮缩放；Shift 单击多选，Shift 拖动空白框选；使用“适应画布”调整视图。
5. 从输出端拖到输入端连接。右侧可修改用途或断开；类型不符、重复占用输入、循环依赖会被阻止。替换输入需要先断开旧连线。
6. 点击“保存”。“新画布”先保存当前草稿；“切换画布”可选择已保存的工作流。离开页面或切换项目时，未保存草稿保留在本次应用会话内；**退出应用前请手动保存**。
7. 选择模板节点或保存节点，点击“生成计划并审批”，核对模板、画布修订、工具和输出目录，再批准制作。
8. 完成后在任务详情查看输出资产，可预览 GLB、打开 Blender 工程。再次运行产生独立目录及新的结果版本。

加入素材：先通过应用“导入素材”复制到项目，再回到画布，选择素材并点击“加入固定引用”。引用记录资产 ID、版本和内容哈希；文件被修改后，“校验固定版本”会报错，需要重新选择。引用目前用于组织画布和类型连线，不能驱动未实现的模型/动画操作。

## 实际完成范围

| 范围 | 当前行为 |
| --- | --- |
| 画布交互 | 节点移动、多选、框选、平移、缩放、适应视图；撤销/重做图编辑 |
| 端口与图校验 | 明确的输入/输出类型、连线用途、单输入约束、无环检查、数量及数据大小上限 |
| 保存 | 项目内多画布、修订号、乐观冲突检查、原子写入及上次保存备份 |
| 异常恢复 | 加载损坏主画布时可显式恢复有效备份；保留损坏文件；不覆盖更高版本格式 |
| 未知节点 | 保存原始字段，重新打开保留；不能执行未知或不支持版本的节点 |
| 资产引用 | 固定版本、SHA-256 校验、项目边界检查；删除节点不删除真实文件 |
| 执行 | 选中目标及其上游依赖；当前执行组合限定为模板建模，或模板建模直接连接保存资产 |
| 实际模板 | 木箱、石柱、灰盒；继续使用原有 Blender 生成、导出、预览和独立重导入验证链 |
| 快照 | 每次计划固定完整图、项目、修订、目标、配方、工具版本；编辑下一版不改变已有任务 |
| 状态 | 记录任务真实状态；参数或输入用途改变后显示需重新运行；仅移动布局不使结果失效 |
| 入库 | 成功后登记资产 ID、版本、文件哈希、验证和来源任务；同一结果节点再次发布递增版本，保留旧文件 |
| 兼容 | 不改旧项目标记、原有 Assets/Generated 布局或用户 Data；打包脚本包含新增模块 |

## 验收证据

自动化回归 **38 项通过、0 项失败**：原有 22 项，加上 16 项工作流测试。覆盖修订冲突、类型错误、循环、项目切换、未知节点、不可变快照、布局与参数失效区别、备份恢复、目录联接越界防护、资产版本和旧文件保留等。

真实 Electron 渲染器检查通过：挂载画布和 SVG 连线、拖动、撤销、参数编辑、断线/重新连线、滚轮缩放、IPC 保存、焦点输入保留、页面往返。此项是程序化操作实际 Chromium DOM；没有把模拟 DOM 测试当作人工视觉验收。未进行完整人工视觉/长时间交互验收。

每轮均在生成计划后修改画布配方，再在运行中切换到另一个隔离项目，验证原配方、原项目输出和资产归属不变。没有使用用户原有项目进行验收。
