# 新架构与接口契约

## 运行结构

本版由独立 renderer、受限 preload 和主进程构成。主进程包含项目与资产服务、任务协调器、Blender 适配器、软件发现/启动服务以及 DeepSeek Gateway。Blender 后台进程独立运行固定脚本。后续扩展应进一步把长耗时索引、模型调用与插件执行移入隔离 worker，维持当前 IPC 和安全边界。

| 选项 | 这次选择依据 | 代价 |
| --- | --- | --- |
| Electron + 本地 HTML/CSS/JS | 本机已有可验证运行时；便携打包无需安装大型构建链；适合多面板与 WebGL | 包体积较大；当前离线运行时较旧，正式发行必须升级 |
| .NET WPF | 本机 .NET SDK 可用，原生 Windows 控件适合工具型桌面 | 需要重新实现 3D/图像视图及更多专门 UI；跨平台代价较高 |
| Tauri / Rust | 可减少分发体积，原生命令边界清晰 | 本次未核实完整 Rust 与 WebView2 发布环境，需额外验证 |
| Avalonia | 可统一桌面 UI 并预留跨平台 | 本次未核实依赖与图形视图分发，新增工程依赖较多 |

选择 Electron 是本次离线预览的工程决定，未复制旧工程业务代码，也未默认沿用 React/Vite/旧 IPC。

## 数据与边界

`Store` 保存项目、工具、任务、调用记录、设置和计划缓存。持久化采用同目录临时写入、fsync、备份与 rename；读取失败时使用经过解析的备份，并保留损坏文件。它不是数据库事务系统；更大规模应迁移到带明确 schema 迁移的数据库。

任务字段包括 id、projectId、projectRoot、sessionId、source、request、recipe、plan、currentStep、progress、status、toolId、approval、logs、outputs、output、validation、error、时间戳。项目根先 realpath；Generated 和 Assets 在写入前再次核实边界；新任务目录 UUID 化。

状态流：待审批→排队→执行中→已验证完成/失败/取消。暂停请求在工具阶段结束后的检查点生效。上次会话的执行中、排队、暂停或取消中任务在恢复时标记 interrupted，不自动重试。恢复为新计划、新任务，保留原记录。

单实例锁防止同一数据目录被两个应用实例同时写入。预览版的单进程协调器同时只运行一个生产任务。

## 已实现 IPC

渲染层只能通过 preload 暴露的 `invoke(method,args)` 请求白名单方法。主进程验证发送窗口与主 frame，再校验方法、参数和实际文件。没有暴露 shell、文件系统句柄、通用 eval 或通用进程启动。

| 组 | 方法 |
| --- | --- |
| 项目 | projectCreate / projectOpen / projectSwitch / projectReveal |
| 资产 | scan / importAssets / assetPreview / assetOpen / reveal |
| 工具 | discover / bindTool / launchTool / openInTool / inspectUE |
| 规划 | localPlan / aiQuote / aiPlan |
| 任务 | taskCreate / taskApprove / taskCancel / taskPause / taskResume |
| 系统 | snapshot / saveSettings / exportDiagnostics / windowControl |

本地计划令牌绑定项目和过期时间。创建任务不代表开始执行；执行需要单独审批。模型只能选择已登记模板或声明不支持，不能提供执行代码。渲染层没有 Node 权限、启用 contextIsolation 与 sandbox，禁止新窗口和外部导航，CSP 限制远程资源。

## Model Gateway

只连接官方 HTTPS `api.deepseek.com/chat/completions`。模型为 `deepseek-flash`，逻辑别名为 `deepseek.default`。限制输出 2048 token，显式 JSON 输出与非思考模式。模型用于有界任务理解，不是任意代码 Agent。

价格按 2026-11-10 官方文档的高峰、缓存未命中值估算：输入 $0.30 / 百万 token，输出 $1.20 / 百万 token。输入上限采用请求 UTF-8 字节数加保守余量，不是精确 token 计数。实际响应 usage 用于费用上限记账；账单以提供商为准。价格记录超过 30 天停止调用；未知模型没有价格就阻止。每日预算使用 UTC 日期。

云端发送仅有用户需求和项目名称、资产分类数量、工具可用性，不发送素材字节、完整路径或源码。确认窗口显示全部发送概要。缓存键绑定完整请求。没有自动重试；超时/连接错误为 unknown 并保留估算预算。

## UE 桥接：设计契约，未实现服务

协议标识 `aigw.ue-bridge/1` 是本软件自定义协议，不是 Epic 官方 API 名称。当前没有监听端口、没有加载 UE 插件、没有实现蓝图读写。预留契约在 `ue-bridge-contract.json`；任何实现必须先验证特定 UE 版本。

能力握手应返回 editorVersion、projectId、sessionNonce、capabilities、readOnly、pluginVersion。主程序只能开放握手中真实存在的 capability。默认 loopback；每会话随机凭据；不能未经授权监听外网。

蓝图写入至少要求：读取资产及版本哈希→生成结构化补丁→显示节点和连线差异→创建备份→人工授权补丁哈希→插件验证允许操作→应用→编译→检查错误→失败回滚或明确报告需要人工恢复。插件不能接收任意 Python/C++/控制台命令作为补丁。

MCP 可以作为其中一种接入方式。原生脚本与专业软件适配器也必须进入统一工具注册、风险、输入输出和审计模型；不要求某个外部 Agent 桌面客户端成为必备依赖。
