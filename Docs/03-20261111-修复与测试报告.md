# 2026-11-11 修复与测试报告

本次基于用户指定的 Application 实际交付版本 preview.1 修复，版本更新为 **2.0.0-preview.3**。压缩包中的 preview.2 是未验收的开发快照，本次未整体覆盖引入该快照。文档中的总控指令及后续建议仅作为参考，不作为额外操作授权。

## 已修复

| 问题 | 修复结果 |
| --- | --- |
| 切换到被移动/删除的项目，失败后当前项目 ID 已改变 | 先检查项目目录，再提交切换；失败保持原项目 |
| 未绑定 Blender 时创建任务失败，同时丢失计划令牌 | 工具校验通过且任务保存后才消费计划，可绑定后重试 |
| 云端规划等待期间切换项目，返回计划绑定到新项目 | 计划始终绑定请求发起时的项目；其他项目不能执行 |
| 一个子目录没有读取权限就导致素材列表整体清空 | 保留可读取资产，记录失败路径与错误码，界面和诊断报告提示 |
| JSON 合法但 tools/calls/settings/cache 结构损坏导致运行错误 | 启动时验证关键容器结构，损坏时进入既有备份恢复流程 |
| 项目打开、软件检测或任务完成后，主体界面仍显示旧内容 | 对项目、工具、资产和设置变化刷新工作区；仅进度变化更新任务面板 |
| 编辑需求后仍可使用旧计划创建任务 | 修改需求时立即清除旧计划 |
| 模板选中后不能取消 | 再次点击选中模板可取消，恢复自动判断 |
| 异步预览返回时面板已替换，可能在旧画布创建预览器 | 校验当前面板实例，并在重绘时作废旧请求 |
| 后台状态刷新可能影响正在填写的设置 | 刷新时保留设置草稿、滚动位置和焦点 |
| 文件扫描后增长，仍按旧尺寸判断预览限制 | 预览读取前重新检查文件当前大小 |
| 打包脚本依赖开发机临时目录和固定旧版本 | 支持指定运行时、输出目录、可选示例项目；从源码/同级目录查找 Docs；动态版本及哈希清单 |

打包会拒绝非空输出目录及与运行时重叠的目录，不复制运行时 resources 中的旧应用、Data 或凭据。打包清单不再把历史测试结果写成新包已验收证据。

## 使用与回退

继续从原路径启动 `Application/AI-Game-Workstation.exe`，界面版本应为 2.0.0-preview.3。业务代码与 Source 已同步，用户原 Data 和项目未迁移或改写；验收均使用专用测试目录。

修改前业务代码位于 `[local drive]\AI-Game-Workstation-Audit-20261111\Backup\app`，修改前源码位于同目录 Source。备份不含用户 Data 或密钥。回退时先关闭应用，将 Backup/app 内文件复制回 Application/resources/app，将 Backup/Source 恢复到 Source，保留 Data。根 README 与旧 build-manifest.json 备份在 Backup 中。

完整便携包重新制作示例（输出必须为空或不存在）：

```powershell
node tools/package-delivery.cjs "[local drive]\AI-Game-Workstation-2.0-preview\Application" "[local drive]\AI-Game-Workstation-NewPackage"
```

第三个位置参数可指定自愿包含的示例项目；默认不包含项目数据。此命令复用现有外壳，正式升级运行时时应提供另行验证的 Electron 分发目录。`Build-Portable.ps1` 保留为应用单体打包入口。
