# AI 游戏开发工作站 3.0.0-alpha.3（模型配置重做 + 工作区真机测试）

## 模型与系统

- **删除了 2.0 旧版规划器**：去掉了设置页的 DeepSeek 旧规划器和「模板制作（2.0）」里的“使用 DeepSeek 规划”按钮。木箱、石柱、灰盒的本地模板保留，3D 创作画布照常能用。
- **模型分成两类添加**：
  - **主模型**：负责理解、规划和操作 UE / Blender，需要通过“工具”检测。可以加几个备选，一键切换当前主模型。
  - **专长模型**：按用途一个一个配置，最多 8 个。预置“视觉识图”“代码 / 蓝图”“3D / 动画 / 美术”“快速省钱”四种，也可以写一段用途说明来自定义。每个专长模型都可以单独选服务商、模型和价格，并且可以随时停用。
- **专长模型怎么被用到**：
  - 主模型多了一个 `consult_specialist` 工具。遇到写代码 / 蓝图、美术方案、看截图这类工作，它会主动去请教对应的专长模型，并且可以把最近的截图一起发过去。
  - 主模型不能识图时，“视觉识图”专长会代它看截图。
  - 专长模型的费用计入账本和单次任务预算。
- 旧版的“视觉模型 / 快速模型”配置会自动迁移成专长模型。

## 虚幻 5 工作区（用 FPS 工程实测）

- **蓝图检查**：
  - 粘贴 UE 节点文本后，节点标题和 UE 里一样（例如“Event BP_OnDeath”“SetCollisionProfileName”“Get Mesh”），注释框会画出来，事件、函数、变量的节点用不同颜色区分。
  - 新增“在 UE 编辑器中检查”（需要连接 AIGW 插件）：
    - 列出工程蓝图
    - 读取蓝图结构（父类、图表、实际实现的函数和事件、蓝图变量）
    - **在 UE 里真编译**，可以编单个蓝图，也可以编整个目录，编译错误会对应到具体蓝图
    - 在 UE 中打开蓝图
- **代码测试**：
  - 中文 Windows 上编译器的中文报错不再乱码，并会单独列出“N 条错误”。
  - 如果 UE 编辑器开着、模块文件被占用，会提示改用实时编码（Ctrl+Alt+F11）或者先关掉编辑器。
  - 重新渲染后，编译目标的选择不会再跳回默认值，并且默认选中 Editor 目标。
- **UE 插件新增 3 个工具**：`blueprint_info`、`compile_blueprints`、`open_asset`，总共 20 个。

# AI 游戏开发工作站 3.0.0-alpha.2（自研 UE 插件 + 真机验证）

## 这一版新增了什么

- **自研 UE 插件 AIGW Bridge**（`v3/unreal/AIGWBridge`）：
  - 支持 UE 5.4 及以上，已在 UE 5.8.3 和 5.6.1 上实测。
  - 补上了官方 Unreal MCP 只支持 5.8+ 的缺口。
  - 共 17 个工具：
    - 读取：读关卡、列资产、视口截图（PIE 运行时截游戏画面）、对准视口
    - 编辑：生成 Actor（基础形状 / 灯光 / 相机 / 出生点 / 文字 / 资产或蓝图）、移动 / 旋转 / 缩放、改名、改颜色（自动建材质实例）
    - 导入：导入 FBX / GLB / OBJ，可直接放进关卡
    - 运行：PIE 启动 / 停止
    - 撤销：**撤销分组**（AI 的多步操作合并成一次 Ctrl+Z）、撤销、重做
    - 高风险：删除、保存关卡（只允许 /Game 下的关卡）、受控 Python
  - 和 Blender 桥接共用同一套协议层：本机 HTTP、随机端口、令牌鉴权、拒绝外部来源，并沿用 L0–L3 权限分级。
  - 每个编辑操作都包在 UE 编辑器事务里，可以撤销。PIE 运行时禁止编辑关卡。
- **一键安装到工程**：在「软件连接 → Unreal Engine（AIGW 插件）」点“安装插件到工程…”，选择 `.uproject` 即可。
  - 不改动工程文件。
  - 重复安装时，旧版本会备份到 `Saved`，不会留在 `Plugins` 里造成重复。
- **AI 助手知道怎么配合两边干活**：系统提示里加入了 UE 单位与旋转约定、撤销分组用法，以及 Blender 导出 → UE 导入的标准流程。

## 真机测试结果（2026-11-13，你的电脑）

| 软件 | 场景 | 结果 |
|---|---|---|
| Blender 4.4.1 | `罐子.blend` 的副本 | 31/31 通过 |
| Blender 4.2.2 LTS | `罐子.blend` 的副本 | 31/31 通过 |
| UE 5.8.3 | 引擎 TP_BlankBP 模板复制的测试工程（OpenWorld 关卡，138 个 Actor） | 53/53 通过 |
| UE 5.6.1 | 同上 | 53/53 通过 |
| 工作站界面（真实 Electron 程序） | 连接 UE 5.8 插件与 Blender 4.4.1 | 两边都显示“已连接”（17 个和 9 个工具） |
| 自动化测试（你的 Windows） | 29 个 Node 测试 + 12 个 Python 测试 | 全部通过 |

UE 测试覆盖的内容：
- 插件随编辑器自动启动，用时 20–60 秒（含编辑器启动）。
- 生成 8 种 Actor，并做变换、改名、改颜色。
- 撤销分组：12 步操作 → 一次撤销全部撤回 → 重做全部恢复。
- Blender 导出的 FBX / GLB 导入 UE，并放进关卡。尺寸正确（1 米 = 100 厘米），颜色带过来了。
- 覆盖保护、脚本安全拦截、删除。
- 拒绝保存模板关卡。
- PIE 启动 → 截取游戏画面 → PIE 中拒绝编辑 → 停止。
- 正常关闭编辑器时会自动删除会话文件。

## 修复

- **工作站界面偶尔打不开，显示“工作站载入失败：v3StatusbarHTML is not defined”**（alpha.1 引入，只在真实程序里出现）。原因：主进程的首个状态返回得比 3.0 界面脚本加载还快。现在会等所有脚本加载完再渲染。另外，界面错误会写入 `Data/logs/renderer.log`，方便排查。
- 软件被强制关闭或崩溃后，留下的会话文件会被识别为“已失效”。连接时会说明原因，不再去连一个已经不存在的端口。
- Blender / UE 桥接：客户端断开连接时，不再在 Blender 控制台或 UE 输出日志里打印吓人的错误回溯。
- UE 的读关卡结果改成紧凑格式，并附上各类 Actor 的数量。大关卡（例如 OpenWorld 模板有上千个 Actor）不会再因为结果被截断而解析失败。

## 已知限制

- 前端工坊（主菜单 / UMG 自动生成）和蓝图图表编辑：UE 的 Python 接口没法往控件树和蓝图图表里加节点，需要给插件加 C++ 模块，排在下一步。
- 插件要求工程能启用 Python Editor Script Plugin 和 Editor Scripting Utilities。插件会自动带上这两个依赖。

# AI 游戏开发工作站 3.0.0-alpha.1（M0 地基）

## 这一版新增了什么

- **AI 助手**（左侧栏第一项）：用自然语言让 AI 直接在 Unreal Engine 和 Blender 里操作。每一步工具调用、截图和结果都显示在对话里，可以随时停止。
- **主模型可任选**：支持 OpenAI 兼容接口（OpenAI、DeepSeek、通义千问、Ollama、vLLM、LM Studio）、Anthropic Claude 和 Google Gemini。可以另设一个视觉模型来看截图，也可以设一个快速模型。添加模型时会自动检测它能不能调用工具、能不能识图。
- **连接 Unreal Engine**：对接 UE 5.8 及以上版本自带的官方 Unreal MCP 插件（实验性）。
- **连接 Blender**：新增 Blender 扩展 AIGW Bridge（`v3/blender/aigw_bridge-0.1.0.zip`，需要 Blender 4.2 及以上）。它提供场景读取、创建物体、移动 / 旋转 / 缩放、改名、材质、视口截图、按 UE 规范导出 FBX / GLB、删除，以及受控的 Python 脚本。
- **权限分级**：
  - L0 只读、L1 编辑：在“自动”模式下直接执行；在“询问”模式下每步都要你确认。
  - L2 脚本、L3 删除 / 项目设置 / 打包等高风险操作：无论哪种模式都要你确认。
  - 每次工具调用都写入审计日志 `Data/v3/audit.jsonl`，日志带哈希链。
- **费用账本与预算**：可以设单次任务上限和每月上限。填写模型单价后，系统会按单价估算费用。
- **项目规则**：写在项目的 `.aigw/rules.md` 里，AI 每次工作都会遵守。
- 2.0 的所有功能（项目、素材、固定模板制作、画布、四个工作区）都保留着，入口改名为“模板制作（2.0）”。

## 三步上手

1. **模型与系统 → 添加模型**：选服务商，填模型名和 API Key，点“保存并检测能力”。主模型必须通过“工具✓”检测，才能操作软件。
2. **软件连接**：
   - **UE**：用 UE 5.8+ 打开工程，在“编辑 > 插件”里启用 **Unreal MCP** 和 **All Toolsets**，重启编辑器，然后回到工作站点“连接”。
   - **Blender**：打开“编辑 > 偏好设置 > 获取扩展”，点右上角 ▾ 选“从磁盘安装”，选择 `aigw_bridge-0.1.0.zip`。启用后回到工作站点“连接”。
3. **AI 助手**：比如输入“在 Blender 里建一个 2 米的木箱，暖棕色，然后截图给我看”。

## 已知限制（按设计方案在后续里程碑完成）

- **UE 方面**：目前完全依赖 Epic 官方的 Unreal MCP 工具集。下面这些还没有接通，计划在 M1 用自研 AIGW Toolset 补上：
  - 把多步操作合并成一次撤销
  - PIE 画面截图
  - 前端工坊（主菜单 / UMG 自动生成）
  - UE 5.6–5.7 的支持
- **官方 Unreal MCP 没有鉴权**：本机其他程序也能调用编辑器工具，不用时请断开。
- **Blender 扩展**：只在模拟环境里测过协议和安全检查，还没有在真实的 Blender 里跑过。首次使用请先在一个测试 .blend 里试一下，有问题告诉我。
- **界面与数据**：仍是 2.0 的原生 JS 界面和 JSON 数据文件。React / TypeScript / SQLite 的重构放在后续里程碑。

## 回退到 2.0

2.0 的完整备份在 `resources\app-backup-2.0.0-preview.5`。回退步骤：

1. 关闭工作站。
2. 把 `resources\app` 改名为 `app-3.0`。
3. 把 `app-backup-2.0.0-preview.5` 改名为 `app`。
